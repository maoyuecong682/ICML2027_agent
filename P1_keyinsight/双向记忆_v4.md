# 工具请求与工具返回的双向记忆 v4

接收者知识现在同时包含 agent 发来的请求，以及该服务实际返回给 agent 的内容。执行 agent 的活动上下文本来就保留工具返回；本轮增加独立、按 agent 隔离的持久观察记忆导出。服务的自身返回标记为 `service_produced_response`，不当作 agent 向服务新增披露的信息。

## 归属与边界

- 服务 S 返回给执行 agent A 的内容，同时属于 S 的已观察知识和 A 的执行观察记忆，不自动复制给其他服务或执行 agent B。
- A 给 B 的报告单独记为 B 收到的消息；B 不因此获得 A 未报告的完整原生工具返回。
- 文件正文、查询结果和记录编号保留原文；支持的结构化返回另外整理为明确对象的字段，供现有恢复器使用。无法解析的返回也保留全文，不丢弃。
- 查询错误保留为错误观察，不把错误正文里出现的邮箱等当作查到的个人资料，也不读取失败事件中未实际送达的成功载荷。
- 读取发生在本服务任何已观察写操作之前，才允许将返回快照标为 `before`；后续快照标为 `after`。这不是对服务全部历史状态的重建。
- 未实际读取的既有资料仍未知；任务指令、私有环境和参考答案不作为接收者知识补入。

## 实现与导出

`p0/tool_memory.py` 从实际 TOOL/MESSAGE 事件导出逐执行 agent 的观察。新执行自动写出 `execution_memory.json`，原有 `messages_a/messages_b` 和官方任务执行流程保持原语义。

`p0_privacy/response_memory.py` 将匹配的真实工具返回建成独立活动节点；`process_graph.build_task_graph` 自动接入，`recovery.memory_from_graph` 读取这个活动层。请求披露数量与旧请求片段标注不因加入返回而增加；返回层保留原文，没有声称已运行 Mem0 压缩。

现有 50/97 个任务使用原始执行日志离线导出，无模型调用、无任务重跑：

- 75 份物理隔离的单接收者输入：`_audit/bidirectional_v4/local_memories/`。
- 50 份按任务组织的接收者记忆：`_audit/bidirectional_v4/receiver_memories/`。
- 50 份按任务、按执行 agent 隔离的执行观察记忆：`_audit/bidirectional_v4/execution_memories/`。
- 完整自然语言视角：`_audit/bidirectional_v4/readable/`。
- 共保留 269 次真实工具返回，其中 11 次错误；执行侧同样保留 269 次按实际目标归属的工具观察。
- 源文件哈希及逐任务计数：`_audit/bidirectional_v4/manifest.json`。

真实诊断：`banking/user_task_9` 的银行资料服务现在能从自身返回恢复 Emma Johnson 及 Apple Street 1；银行服务能从自身返回恢复余额 1810.0、交易 #7 的金额 1100.0。没有向银行服务补入资料服务的姓名。

旧版 v1-v3 记忆和评估结果不覆盖。**本轮没有重跑隐私恢复率或联合新增率，旧 0% 不能直接当作新版结果。**
