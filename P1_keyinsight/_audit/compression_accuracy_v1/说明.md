# 50任务三层压缩与隐私判断评估

使用既有50/97任务以及message_gain_v5每个任务已经选定的一条真实消息。没有加入P标识改编或其他篡改消息。历史截止到该消息之前；新消息原文在三组中完全相同，后续工具返回和agent报告均不进入判断。

三组共享范围完全一致，均为同任务内显式允许共享的业务服务。0保留完整活动共享历史和共同的Mem0处理；12345在0上实际执行现有五个结构简化开关；TRAIL在12345的活动表示上进一步整理记录、字段角色、主体、时间和跨接收者相同标识线索。TRAIL为本轮实现的关联保留原型，不把新增共享权限当作压缩效果。

Mem0使用1.0.5和deepseek-flash。完整工具记录只允许等值分组，逐项核对完整文本、来源和出现记录不变；不允许以“内容相近”合并不同工具或不同字段。对于长文本，更新阶段使用来源ID传输，程序只按已经验证的ID组恢复原文字节，避免模型重复长JSON时转义错误或截断。空历史不伪造Mem0模型调用。所有语义输入在三组中一致。

0/12345不读取Graphiti实体的全任务摘要，防止后续信息进入当前前缀；只保留当前有证据的活动节点。审计、私有环境、人工答案、旧的被吸收/移出节点不作为检测器旁路输入。TRAIL从12345活动表示生成，保留全部活动关系的主体、谓词、对象、上下文和接收者，并保留请求/返回记录。跨服务字符串相等只作为连接线索，需要兼容的语义才能推出隐私。

## 参考标签

评估单位是“同一真实消息＋同一历史下，一个具体主体/记录的一个隐私字段是否可恢复”。风险指信息可恢复，不指越权，也不指新增消息相对历史的边际泄露。

正例来自未压缩原始可见证据中的明确类型事实、明确局部绑定或固定有限关系规则的证明，每个正例保留原始事实ID。负例来自独立的任务前私有参考记录：参考值没有出现在任何可见原始消息中，也没有相应已证实关系。没有创建假邮箱、假参与者或假消息。基准覆盖这套有证据的字段与关系，不把它解释成任意自然语言推断的完备真值集。

每任务按固定SHA256顺序最多选12个正例、12个负例，在压缩和全部检测之前保存。总计352个正例、402个负例；这些是具体隐私判断项，不是754条消息。恢复问题只传主体、字段和必要时间状态，参考值、风险标签和证明留在评估侧。三组使用同样的DeepSeek模型、提示词、温度和问题列表。

## 四项指标

- 有风险的漏过率：FN / (TP + FN) × 100。
- 误判率：FP / (FP + TN) × 100，即无风险项被报警的比例。
- 隐私记忆存储空间：检测器实际读取的活动记忆JSON文件的紧凑UTF-8字节数。包括TRAIL关联索引；不包含独立审计日志、数据库缓存和重复快照。
- 检测隐私消耗的DeepSeek token：当前冻结表示的一轮检测实际API usage.total_tokens，包含输入和输出；当前调用发生格式重试时累加所有响应的token。Mem0/构图成本属于共同准备阶段，未混入检测成本。表示校正前的调用保留在previous_representation_v1中，独立于最终条件的单轮成本。

10个任务无正例、3个任务无负例，对应比率写N/A，不写0%。三行依次是0（Mem0）、0+12345、0+12345+TRAIL。CSV只包含四项指标和必要行列标签，不包含额外统计列。

## 复现与审计

prepare.py prepare固定原始输入与参考标签；run_api.py compress运行共同Mem0；prepare.py build生成递进三层记忆；run_api.py detect实际调用DeepSeek；score_and_verify.py复算混淆矩阵、存储和token；export_csv.mjs通过Artifact Tool核对并输出50份CSV。

逐任务目录保存原消息、前缀历史、标签及证明、三层记忆、独立模型请求/响应与API usage。summary.json和artifact_verification.json记录最终校验。原始任务执行日志、原人工标注表、此前实验结果均不修改。
